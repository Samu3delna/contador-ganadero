ONVO Pay Aprobado — Modo LIVE

Guía de Activación ONVO Pay en Producción

Arquitectura real de ContadorGanadero (Cloudflare + Render): cómo funcionan juntos la API REST, el SDK Web y el Webhook, y qué configurar exactamente según tus capturas.

⚡ ¿Usaremos Webhook y API? — ¡SÍ, AMBOS trabajan en equipo!

El código de ContadorGanadero ya tiene programada la integración completa híbrida (backend/services/onvoService.js, backend/controllers/onvoController.js y frontend/src/components/billing/OnvoCheckoutModal.jsx). Cada uno cumple un rol indispensable:

🔌 1. API REST + SDK Web (Inicio y Cancelación)

  • Crear Cliente (API): POST /v1/customers cuando el usuario da clic en Mejorar a Pro.
  • Crear Suscripción (API): POST /v1/subscriptions con tu ONVO_PRICE_PRO e inyecta metadata: { tenantId, planId: 'pro' }.
  • Cobrar con Tarjeta (SDK Web): El modal abre window.onvo.pay() con tu Llave Pública LIVE para capturar la tarjeta de forma segura.
  • Cancelar (API): DELETE /v1/subscriptions/:id cuando el usuario cancela desde la app (ONVO no envía webhook de cancelación).

🔔 2. Webhook (Activación de Plan y Renovación Mensual)

  • Endpoint en Render: POST https://contador-ganadero.onrender.com/api/onvo/webhook.
  • Seguridad: Verifica el header X-Webhook-Secret con comparación criptográfica timing-safe.
  • Idempotencia: Guarda cada evento en SubscriptionEvent en MongoDB para nunca duplicar efectos.
  • Activación y Gracia: Con subscription.renewal.succeeded activa el Plan Pro y resetea cuotas; con subscription.renewal.failed da 7 días de gracia.

3

Crear el Webhook y Elegir los Eventos (Tus Capturas #1 y #2)

Webhooks ONVO

En la pantalla de Webhooks → + Agregar webhook → Crear un destino de eventos (tu Captura #1):

✅ Eventos OBLIGATORIOS (Sección Suscripciones)

Escribe subscription en el buscador de eventos o baja a la sección de cargos recurrentes y marca estos dos:

  • subscription.renewal.succeeded
    Activa el Plan Pro en el primer cobro y renueva cuotas cada mes.
  • subscription.renewal.failed
    Pone la finca en periodo_gracia (7 días) si falla la tarjeta.

📋 Eventos Opcionales (Intenciones de Pago — Captura #1)

Los que aparecen en tu primera captura se pueden marcar como respaldo de auditoría (se guardan en SubscriptionEvent):

  • payment_intent.succeeded (Pago exitoso)
  • payment_intent.failed (Pago fallido)
  • payment_intent.canceled (Pago cancelado)
URL del destino (Paso 2 "Configurar destino" en ONVO):
https://contador-ganadero.onrender.com/api/onvo/webhook
🔐 Secreto del Webhook (X-Webhook-Secret): Cuando termines el paso 3 ("Revisar y crear"), ONVO te entregará el Secreto de firma del endpoint. Cópialo y guárdalo en Render como ONVO_WEBHOOK_SECRET.
4

Configurar las 4 Variables en Render (contador-ganadero-api)

Render Environment

Ve a tu servicio contador-ganadero-api en Render → pestaña Environment y agrega/actualiza estas 4 variables:

ONVO_SECRET_KEY=onvo_live_secret_key_... ONVO_PUBLISHABLE_KEY=onvo_live_publishable_key_... ONVO_PRICE_PRO=<ID_DEL_PRECIO_MENSUAL_10_USD_EN_ONVO> ONVO_WEBHOOK_SECRET=<SECRETO_DEL_WEBHOOK_CREADO_EN_ONVO>
🔄 Cómo fluye un pago LIVE de principio a fin
Paso 1 • Frontend

Clic en "Mejorar a Pro"

En PlanesPage.jsx el usuario elige Pro ($10/mes) y llama a POST /api/onvo/checkout.

Paso 2 • API ONVO

Cliente + Suscripción

Render crea el Customer y la Subscription (allow_incomplete) usando ONVO_SECRET_KEY y ONVO_PRICE_PRO.

Paso 3 • SDK Web

Formulario de Tarjeta

OnvoCheckoutModal.jsx renderiza window.onvo.pay() con ONVO_PUBLISHABLE_KEY y confirma la tarjeta.

Paso 4 • Webhook

Activación Automática

ONVO envía subscription.renewal.succeeded a /api/onvo/webhook y el Tenant pasa a Plan Pro.
