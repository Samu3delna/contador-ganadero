# Direcciones visuales de ContadorGanadero Mobile

Abrir `index.html` para comparar Archivo, Terreno y Horizonte, o `terreno.html` para explorar la dirección elegida. También pueden servirse con un servidor de archivos estáticos.

Los prototipos contienen datos ficticios, estado en memoria y operaciones simuladas. Las fuentes y sus licencias están en `assets/fonts/`. No cargan datos productivos; solo los enlaces legales abren la web al seleccionarlos.

El propietario seleccionó **Terreno** para implementar directamente en Expo. El resultado real está en `mobile/`; su informe es `mobile/docs/terreno-implementation.md`.

Estos HTML son referencias de diseño, no capturas de la app nativa ni una nueva compilación publicada. Deska está indisponible en esta tarea y Figma aún requiere conexión.
